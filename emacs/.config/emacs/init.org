* Introduction
Kickstart.emacs is *not* a distribution. It is a template for your own configuration,
inspired by kickstart.nvim. This is now /your/ config: it is edited in this file
(=init.org=) and tangled to =init.el= on save.

Useful help keys: =C-h t= (tutorial), =C-h f= / =C-h v= / =C-h k= (describe function,
variable, key), =C-h m= (current modes), =C-h i= (manuals).

Conventions used in this file:
- Everything is configured through =use-package=. Keys are bound with =:bind=, hooks with =:hook=.
- Leader keys (=SPC=) are declared next to the package that owns the command
  (see [[#leader-keys][Leader Keys]]). There is no general.el.
- Packages whose keys live in =evil-motion-state-map= use =:after evil= so the map exists
  when the bindings are made.

** Auto-tangle Configuration file
Tangles =init.org= to =init.el= whenever it is saved, then refreshes the package quickstart file.
If this code is never loaded (error earlier in the file), fix the error and tangle manually with =C-c C-v t=.

#+begin_src emacs-lisp
(defun start/org-babel-tangle-config ()
  "Tangle init.org and refresh `package-quickstart' after saving it."
  (when (and buffer-file-name
             (file-equal-p buffer-file-name
                           (expand-file-name "init.org" user-emacs-directory)))
    (let ((org-confirm-babel-evaluate nil))
      (org-babel-tangle)
      (package-quickstart-refresh))))

(add-hook 'org-mode-hook
          (lambda () (add-hook 'after-save-hook #'start/org-babel-tangle-config nil t)))
#+end_src

* Important to load first
** Evil Mode
Vim emulation. Toggle with =C-z=.

Variables that start with =evil-want-= must be set /before/ evil loads, so they use =setq= in =:init=
(=:custom= is too late for some of them).

=SPC= is freed in the motion map so other packages can bind =SPC f f=, =SPC s f=, ... (see [[#leader-keys][Leader Keys]]).
This block must stay before every block that binds =SPC= keys.

#+begin_src emacs-lisp
(use-package evil
  :hook (after-init . evil-mode)
  :init
  (setq evil-want-keybinding nil        ; evil-collection handles other modes
        evil-want-integration t
        evil-want-C-u-scroll t
        evil-want-C-i-jump t
        evil-want-Y-yank-to-eol t
        evil-want-fine-undo t
        evil-undo-system 'undo-redo
        evil-vsplit-window-right t
        evil-split-window-below t)
  :config
  (evil-set-initial-state 'eat-mode 'insert)
  :bind
  (:map evil-motion-state-map
   ("SPC" . nil)                 ; frees SPC: it becomes the leader prefix
   ("RET" . nil)                 ; lets org-return-follows-link work
   :map evil-normal-state-map
   ("-"     . dired-jump)
   ("RET"   . ignore)
   ("C-j"   . ignore)
   ("C-k"   . ignore)
   ("C-S-v" . clipboard-yank)
   :map evil-insert-state-map
   ("C-p"   . completion-at-point)

** Leader Keys
:PROPERTIES:
:CUSTOM_ID: leader-keys
:END:
=SPC= is the leader in evil motion/normal state. Bindings are declared by each package
with =:bind (:map evil-motion-state-map ("SPC x y" . command))=:

| Prefix | Group  | Declared in                          |
|--------+--------+--------------------------------------|
| SPC f  | Find   | this block, Consult                  |
| SPC s  | Search | this block, Consult, Flymake         |
| SPC g  | Git    | Magit                                |
| SPC o  | Org    | Org Mode                             |

Labels for the prefixes are set in the Which-Key section.
Neovim-style LSP keys (=grn=, =gra=, =grr=, =gri=, =grt=) are in the Eglot section.

Built-in commands:

#+begin_src emacs-lisp
(defun start/open-init-file ()
  "Open init.org."
  (interactive)
  (find-file (expand-file-name "init.org" user-emacs-directory)))

(defun start/open-notes ()
  "Pick a note (*.org or *.md) from ~/Documents/Notes/personal/."
  (interactive)
  (let* ((dir (expand-file-name "~/Documents/Notes/personal/"))
         (files (mapcar (lambda (f) (file-relative-name f dir))
                        (directory-files-recursively dir "\\.\\(org\\|md\\)\\'")))
         (choice (completing-read "Notes> " files nil t)))
    (find-file (expand-file-name choice dir))))

(use-package emacs
  :after evil
  :bind
  (:map evil-motion-state-map
   ("SPC f c" . start/open-init-file)
   ("SPC f n" . start/open-notes)
   ("SPC f s" . scratch-buffer)
   ("SPC s c" . describe-command)))

(use-package flymake
  :ensure nil
  :after evil
  :bind
  (:map evil-motion-state-map
   ("SPC s d" . flymake-show-buffer-diagnostics)))
#+end_src

* Development
** Eglot
Built-in LSP client. Servers are not installed by Eglot: install them yourself and put them in =PATH=
(gopls, rust-analyzer, pyrefly, ...).

Hooks use the tree-sitter modes: with =major-mode-remap-alist=, the classic mode hooks
(=python-mode-hook=, =c-mode-hook=, ...) never run.

Neovim 0.11 default LSP mappings:

| Key        | Action                  | Provided by                         |
|------------+-------------------------+-------------------------------------|
| =gd=       | definition              | evil-collection-eglot               |
| =K=        | hover docs              | evil-collection-eglot               |
| =C-t=      | pop back                | evil-collection-eglot               |
| =grn=      | rename                  | below                               |
| =gra=      | code actions (n, v)     | below                               |
| =grr=      | references              | below                               |
| =gri=      | implementation          | below                               |
| =grt=      | type definition         | below                               |
| =gO=       | document symbols        | below                               |
| =[d= =]d=  | prev / next diagnostic  | below                               |

#+begin_src emacs-lisp
(use-package eglot
  :ensure nil
  :hook ((c-ts-mode c++-ts-mode python-ts-mode go-ts-mode
          rust-ts-mode lua-ts-mode) . eglot-ensure)
  :custom
  (eglot-events-buffer-config '(:size 0)) ; no LSP event log (replaces obsolete eglot-events-buffer-size)
  (eglot-autoshutdown t)
  (eglot-report-progress nil)
  :config
  ;; gopls and rust-analyzer are already Eglot defaults; pyrefly is the custom one.
  (add-to-list 'eglot-server-programs
               '((python-mode python-ts-mode) . ("pyrefly" "lsp")))

  (evil-define-key* 'normal eglot-mode-map
    "grn" #'eglot-rename
    "grr" #'xref-find-references
    "gri" #'eglot-find-implementation
    "grt" #'eglot-find-typeDefinition
    "gO"  #'consult-imenu
    "]d"  #'flymake-goto-next-error
    "[d"  #'flymake-goto-prev-error)
  (evil-define-key* '(normal visual) eglot-mode-map
    "gra" #'eglot-code-actions))
#+end_src

** Cape
Completion-at-point extensions. Capfs listed in =merge-backends= are combined into one candidate list;
capfs in =separate-backends= (like =cape-file=) cannot be merged. Each capf adds a small runtime cost.

#+begin_src emacs-lisp
(use-package yasnippet-capf :defer t)

(defun start/setup-capfs ()
  "Configure completion backends for the current buffer."
  (let ((merge-backends (list #'yasnippet-capf   ; yasnippet snippets
                              #'cape-dabbrev     ; words from current buffers
                              #'cape-keyword))   ; language keywords
        (separate-backends (list #'cape-file          ; paths
                                 #'cape-elisp-block))) ; elisp in Org/Markdown
    ;; No keywords or snippets in git commit messages
    (when (bound-and-true-p git-commit-mode)
      (dolist (backend '(cape-keyword yasnippet-capf))
        (setq merge-backends (remq backend merge-backends))))
    ;; Elisp symbols only in Elisp modes
    (when (derived-mode-p 'emacs-lisp-mode 'ielm-mode)
      (setq merge-backends (cons #'cape-elisp-symbol merge-backends)))
    ;; LSP candidates when Eglot manages the buffer
    (when (bound-and-true-p eglot--managed-mode)
      (setq merge-backends (append merge-backends (list #'eglot-completion-at-point))))
    (setq-local completion-at-point-functions
                (append separate-backends
                        (list (apply #'cape-capf-super merge-backends))))))

(use-package cape
  :after corfu
  :hook ((eglot-managed-mode prog-mode text-mode git-commit-setup) . start/setup-capfs))
#+end_src
